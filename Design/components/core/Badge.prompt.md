A status stamp — square shoulders, a 2px rule down the leading edge in the tone's colour, label in wide-tracked uppercase mono. Reads as something measured, like the step counter and the meetup code.

```jsx
<Badge live>Everyone is in</Badge>
<Badge variant="secondary">Waiting on replies</Badge>
<Badge variant="brand" live>Wants to ride with you</Badge>
<Badge variant="outline">placeholder</Badge>
```

Use `live` only when the state is happening right now — it hops. Never a pill, never a bare dot.
