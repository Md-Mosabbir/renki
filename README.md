## Project Description

Renki is a university-exclusive carpooling platform: it matches students going the same way so they can share one ride to or from campus. Verified students create, join and manage rides within a trusted campus community.

Renki does not dispatch vehicles and has no driver, no fare and no payment — none of them exist in the schema. It matches people, then hands the trip off to a ride-hailing app with both ends prefilled, and whoever taps that pays and settles up socially. Calling it "ride sharing" would name the thing Renki hands off _to_.

The project aims to make daily commuting simpler, safer, and more accessible through university-based authentication, ride matching, and an easy-to-use interface.
